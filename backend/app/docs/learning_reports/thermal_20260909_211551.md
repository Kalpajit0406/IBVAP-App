`notebooks/train_thermal_colab.ipynb`: 30 epochs, imgsz 640, batch 32,

## Caveat — scope of this model

The `dataset` field reads "LLVIP (+ FLIR ADAS)" but that string is fixed in the
notebook, not derived. On RGB test frames this model predicts only `person`,
which suggests **LLVIP person-only** (no Roboflow key was pasted, so no FLIR
thermal vehicles). Check the notebook's Step-3 `boxes per COCO id:` line: `{0: …}`
alone = person-only night model; `2, 3, 5, 7` present = thermal vehicles too. To
add vehicles, re-run with `python training/datasets_fetch.py --thermal
--roboflow-key <key>` then `python training/train_thermal.py`.

Also verify infrared vs low-light-RGB: LLVIP ships paired `infrared/` +
`visible/`. A base mAP50 of 0.62 is on the high side for pure white-hot IR — if
the assemble step pulled `visible/` too, this is more a low-light model than a
thermal one. Both are "night"; the `counts:` line in Step 3 shows which.
