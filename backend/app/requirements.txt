# ANPR — number-plate recognition (ibvap/anpr.py, anpr.enabled in config.yaml).
# Two stages: a YOLO plate detector + a plate-text OCR. The OCR backend is
# `fast_plate` (fast-plate-ocr — plate-specific ONNX model, no torch at runtime,
# recommended) and falls back to EasyOCR (generic English) if it isn't installed.
# If NEITHER is installed the ANPR engine disables itself and the rest of the
# pipeline is unaffected.
fast-plate-ocr[onnx-gpu]>=1.0     # OCR backend; use [onnx] on a CPU-only box

# Training only (Kaggle notebook / training/train_anpr.py):
#   pip install "fast-plate-ocr[train]"   kaggle   roboflow
